# Список задач (To-Do List)

Небольшое веб-приложение «Список задач»: можно добавлять задачи, отмечать их
выполненными, удалять и редактировать. Список сохраняется в браузере, поэтому
после перезагрузки страницы все задачи остаются на месте.

## Демо

🔗 Vercel: https://todo-vue-ruby-tau.vercel.app

🔗 GitHub Pages (открывается в России без VPN): https://anastasia-gamova.github.io/todo-vue/

Обе версии — одно и то же приложение, опубликованы автоматически при каждом
push в ветку `main`.

## Возможности

- ➕ Добавление задачи — по нажатию Enter и по кнопке «Добавить». Пустую задачу
  добавить нельзя.
- ✅ Отметка задачи выполненной.
- 🗑️ Удаление задачи.
- ✏️ Редактирование по двойному клику: **Enter** — сохранить, **Esc** — отменить.
  Если очистить текст и сохранить, задача удаляется.
- 💾 Сохранение в `localStorage` — данные не теряются после перезагрузки.
  Если в хранилище попали «битые» данные, приложение не падает, а начинает
  с пустого списка.
- 🔎 Фильтры «Все / Активные / Выполненные» и счётчик оставшихся задач.
- 🧹 Кнопка «Удалить выполненные».
- 📭 Понятное пустое состояние, когда задач нет.
- 📱 Адаптивная вёрстка — удобно и на телефоне, и на компьютере.
- ♿ Доступность: подписи у полей и кнопок, работа с клавиатуры, поддержка
  тёмной темы.

## Стек

- [Vite](https://vite.dev/) — сборка и дев-сервер
- [Vue 3](https://vuejs.org/) — Composition API, `<script setup>`
- [TypeScript](https://www.typescriptlang.org/) — строгий режим (`strict`), без `any`
- [Vitest](https://vitest.dev/) — тесты
- [ESLint](https://eslint.org/) — проверка кода
- [Husky](https://typicode.github.io/husky/) — проверки перед коммитом

## Структура проекта

```
src/
  components/        # компоненты интерфейса
    TaskInput.vue    # поле добавления задачи
    TaskItem.vue     # одна задача (просмотр + редактирование)
    TaskList.vue     # список задач
    TaskFilters.vue  # фильтры, счётчик, «удалить выполненные»
  composables/
    useTasks.ts      # вся логика работы с задачами (отдельно от компонентов)
  styles/
    main.css         # стили
  types.ts           # типы Task и Filter
  App.vue            # сборка интерфейса
  main.ts            # точка входа
tests/
  useTasks.test.ts   # тесты логики
  setup.ts           # окружение для тестов (in-memory localStorage)
```

Вся логика задач вынесена в composable `src/composables/useTasks.ts` и не зависит
от компонентов — это упрощает тестирование и переиспользование.

## Как запустить локально

Нужен установленный [Node.js](https://nodejs.org/) (версия 18 или новее).

```bash
# установить зависимости
npm install

# запустить дев-сервер (адрес появится в консоли, обычно http://localhost:5173)
npm run dev
```

## Как запустить тесты

```bash
# прогнать тесты один раз
npm run test

# тесты в режиме наблюдения (перезапуск при изменениях)
npm run test:watch
```

## Другие команды

```bash
npm run build   # сборка продакшн-версии в папку dist
npm run preview # локальный просмотр собранной версии
npm run lint    # проверка кода ESLint
npm run check   # всё сразу: lint + тесты + build
```

Перед каждым коммитом Husky автоматически запускает `npm run check`
(линт, тесты и сборку). Если что-то не проходит — коммит не создаётся.
